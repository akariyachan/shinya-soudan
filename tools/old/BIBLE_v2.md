# 深夜の相談室 — 設定資料（ストーリーバイブル）＆データ形式　第二版

このファイルは story/ を書く人のための共通資料。**名前・地名・時刻・フラグ名はここに書いたものを厳守**すること。
第二版で「時をこえる相談室」「彼の人生の三つの道」を入れた。旧版と食い違うところは、すべてこちらが正しい。

## 0. 文体の約束
- 静かで、少しユーモアがあり、説教くさくない。昭和の深夜ラジオと純喫茶の空気。地の文は「相談員の目」から（主語「わたし」は使ってよいが多用しない）。
- 相談員（プレイヤー）は **性別・年齢を書かない**。名前もない。呼ばれ方は「相談員さん」「あなた」「店の人」。一人称は「わたし」。「彼」「彼女」で相談員を指さない。
- 悩みは「小さいけれど本人には大きい」。具体的な物（杏仁豆腐、進路調査票、炊飯器の目盛り、胃薬、コーンポタージュの缶…）で語らせる。
- 相談員は答えを与える人ではない。ちょうどいい返事とは「相手の言葉を受け止めて、少しだけ視点を足す」もの。
- 地の文で珈琲、窓の外のネオン、月、真空管ラジオのノイズ、黒電話、坂道などを描く。
- 「以下同様」「（略）」などの省略は禁止。全部書き切る。

## 1. 世界

- 町：**朝凪町（あさなぎちょう）**。駅前から商店街「**ひかり通り**」が延び、その外れの坂の途中（二丁目）に店がある。
- 店：**純喫茶ともしび**。創業五十年余り。去年の冬（千鶴が亡くなった冬）に閉店し、今年の夏から相談員が「**真夜中の相談室**」として夜だけ開けている（三か月ほど）。営業は 23:30 ごろ〜夜明け前。メニューはネルドリップのブレンド、ほうじ茶、ホットミルク、クリームソーダ（夏の名残で一応ある）、ウインナーコーヒー。お代は「お気持ちで」。カウンター五席とテーブル二つ。**黒電話**（赤いダイヤル式、店の古い番号「朝凪 2-1104」）、真空管ラジオ、本棚、観葉植物、柱時計。窓の外に駅前のネオン。
- レジ横に**店のマッチ箱**（ともしびの古いマッチ。灯台の絵と店の電話番号が刷ってある）が積んであり、相談員は帰っていく人によく「よかったら」と渡す。**このマッチ箱が、時をこえて人から人へ番号を運ぶ小道具になる**（後述）。
- 坂の下に **コンビニ「ハッピーマート朝凪二丁目店」**（イートイン二席あり）。向かいに**ドラッグストア「くすりのコトブキ」**（22時閉店）。店の前に自販機。
- 駅前ロータリーの**電話ボックス**は、相談員の「今」では**今年の春に撤去された**（相談員は撤去の張り紙を見た記憶がある）。
- 地元局 **FMあさなぎ 78.3MHz**。深夜番組「**ナツメの真夜中便（まよなかびん）**」月〜金 23:00〜1:00。DJ はナツメ。スタジオは店から歩いて五分の雑居ビル四階。
  - 締めの言葉（毎晩同じ）：「**眠れない人も、眠らない人も。朝が来るまでは、起きてる同士で。――ナツメでした。おやすみなさいは、まだ言わないでおきますね。**」
  - ナツメは番組でときどき「街のどこかに、真夜中だけ灯りのつく窓があるらしいですよ」と話す。
- 季節：第一夜は十月の終わり、第五夜は十二月はじめ（初雪）。夜と夜のあいだは一〜二週間あく。
- 月と天気（相談員の「今」の空）：第一夜＝細い三日月／第二夜＝上弦の月、風が強い／第三夜＝一晩じゅう雨／第四夜＝満月、二丁目一帯が停電（1:40ごろ〜3:30ごろ。黒電話は停電でも使える）／第五夜＝初雪、夜明けに雪がやむ。

## 2. 物語の秘密（どんでん返し）— プレイ中は絶対に明かさない

### 2-1. 相談員とナツメ（旧版どおり）
1. **相談員自身が、十年前にここへ来た相談者だった。** 十年前の冬、眠れずに夜の町を歩いて、灯りのついていたともしびに入った。マスター（当時は口ひげと黒縁眼鏡）は「眠れないなら、眠らなくていい。朝までいなさい」と珈琲を出した。その後相談員は町を離れ、また眠れなくなり、今年の春に戻ってきた。閉まったともしびの扉に手書きの貼り紙「**夜の店番、求む。珈琲を淹れられる方。夜だけ。ご連絡は郵便受けへ。**」。手紙を入れると、返事と鍵が届いた。大家の署名は「瀬尾」。条件は三つ：「**一、黒電話は外さないこと。二、眠れない人を追い返さないこと。三、自分も、ちゃんと眠ること。**」追伸「話は、近すぎても遠すぎても届かない。」大家とは一度も会っていない。
2. **十年前のあの夜、カウンターの隣で泣いていた若い女性がナツメ。** 当時二十二歳、FMあさなぎの新人AD。相談員は寝不足で、彼女のマグを取り違えて口をつけ、「あ……すみません。……起きてる同士ですね」と言った。ラジオでは古い歌謡曲「**真夜中のメリーゴーラウンド**」（1978年、小早川ルミ。架空）。相談員は彼女の顔を覚えていない。ナツメは覚えている。**締めの言葉「起きてる同士で」はあの一言から。**
3. **貼り紙を書いたのはナツメ**（源さんの代筆）。応募の手紙で相談員があの夜の人だと気づいた。
4. **源さん＝瀬尾源一郎＝ともしびの元マスター＝大家。** 第三夜に相談者として来るが大家だとは言わない（ヒントは散らす）。
5. **黒猫ヨル**：千鶴の飼い猫。からし色のマフラー（千鶴の手編み）。相談員にだけ人の言葉で話す（ように聞こえる）。一人称「わたし」、語尾「〜である」「ふむ」「〜したまえ」。

### 2-2. 時をこえる相談室（第二版の中心。**プレイ中は決してはっきり言わない**）
- **この店の黒電話の回線と、真夜中の扉は、時間をこえてつながっている。** 「眠れない夜」どうしが、年をまたいで同じ店に灯りを見つける。千鶴は生前「この電話はね、ときどき、よその夜につながるのよ」と笑っていた。源さんは本気にしていなかったが、だから「黒電話は外さないこと」を条件にした。真相は**エピローグでだけ**、源さんの夜明けの電話と、最後の「彼の物語」で明かす。
- 相談員の「今」＝第一〜第三夜の相談者（七海・湊・桐島・梢・源さん）とナツメの「今」。これを **「今」** と呼ぶ。
- **陽向は「今」の五年前**から、公衆電話で電話をかけてくる。
- **遥・ひより・拓海・澄江は「今」の十二年後**の人。遥と澄江は扉から入ってくる。ひよりと拓海は電話。
- 誰も「何年」とは言わない。西暦・元号は**どこにも書かない**。相談員も気づかない（気づきかけても、寝不足のせいにする）。

### 2-3. 彼＝陽向＝湊＝拓海（**同一人物**。プレイ中は別々の相談者に見せる）
- 本名 **三好 湊（みよし・みなと）**。生まれたときは **戸川 湊**。十七歳（高二の秋）で両親が離婚し、母方の姓・三好になる。
- **陽向（ひなた）**は、十六歳の彼が電話で名乗った**とっさの偽名**。梢の歌「午前二時の自販機」の歌詞「ひなたの残りの、ぬるい缶」から借りた。姓の「戸川」は本当。
- **拓海（たくみ）**は、三十三歳の彼の**仕事用の名前**。祖父（母方、三好のおじいちゃん。腕時計をくれた人）が、本当は彼に付けたかった名前。独立したときにその名前を名乗った。
- 三人が共有する手がかり（各夜に一つか二つずつ。強調しない）：
  - **腕時計**：祖父の形見の、銀色の古い手巻き。陽向の電話の途中で、電話ボックスの棚にぶつけて**四時の位置のガラスにひびが入る**（「あ、時計……」）。湊も拓海も、四時の位置にひびの入った古い腕時計をしている（湊はカウンターで袖から見える。拓海は「古い時計、ガラス割れてるのに直さなくて」）。遥ルートでは遥とひよりも「パパの時計、ガラスがわれてる」と言う。
  - **左手の親指の付け根の小さな傷**：陽向「昨日、カッターで鉛筆削ってて」。湊は話しながら親指の傷をこする癖。拓海も「親指の古傷をこする癖があって」と自分で言う。
  - **口癖**「……って、変ですかね」。三人とも、自分の本音を言ったあとに付ける。
  - **月と猫の落書き**（描き続けた道でだけ。陽向のノート、湊のレシートの裏、拓海の仕事）。
  - **コーンポタージュの缶の底を、指で二回たたく**癖（最後の粒を落とすため）。
- 彼の時系列：
  - 中三の秋〜冬（「今」の六年前）：両親の不仲で家にいられず、不登校。昼間はともしびの窓際で絵を描いていた（源さんは黙って置いてくれた。千鶴がクリームソーダを出し、帰りにマッチ箱をくれた）。冬の夜、ライブハウス「**夜間飛行**」の中高生の日に、十五歳の梢が「午前二時の自販機」を歌うのを聴き、救われる。春から学校へ。
  - 高一の秋（「今」の五年前）＝**陽向の夜**（第一夜）：朝凪高校一年。同じクラスに、あの歌のコズエ（早瀬梢）がいる。向こうは彼を知らない。
  - 高二の秋：両親離婚、三好姓に。
  - 「今」（二十一歳）＝**湊の夜**（第二夜）：高校卒業後、進学せずハッピーマート夜勤三年目。
  - 「今」の十二年後（三十三歳）＝**拓海の夜**（第五夜）：フリーランス。

## 3. 彼の人生の道（**最重要**）— 隠れフラグとルート

### 3-1. 陽向（第一夜）で立つフラグ
| フラグ | 立つ返事 | 意味 |
|---|---|---|
| `hi_draw` | 絵のことで「描くのが好きなのと、夢にするのは別でいい」という方向のちょうどいい返事 | 描くことを「将来の夢」に変えずに、好きなまま持っていていいと知る → 描き続ける |
| `hi_no` | 頼まれごとの話で「すぐ返事しなくていい、『考えさせて』と言っていい」方向のちょうどいい返事 | 断る／保留する練習をはじめる |
| `hi_kozue` | コズエの話で「返事のいらない言葉として、救われたことを伝えてみる」方向のちょうどいい返事 | 次の日、梢に「あの曲に救われた」と言う → 梢に誘われ、夜光虫のベースになる（高一の冬〜高三の夏） |

### 3-2. 湊（第二夜）での変化と、立つフラグ
陽向のフラグで、**湊の境遇がはっきり変わる**（同じ人の別の人生として書く）。
| 条件 | 湊の境遇 |
|---|---|
| `hi_draw` | 今も描いている。レシートの裏や発注用紙の余白に、常連客を動物にした落書き（杏仁豆腐の人＝うさぎ、胃薬の人＝ふくろう、など）。スケッチブックは五冊目。誰にも見せたことがない |
| `!hi_draw` | 高二の夏に描くのをやめた（「描いてどうすんの、って思っちゃって」）。「なんにもないんすよ、おれ」。ただ、話しながら無意識にレシートの裏に月を描いてしまう（手がおぼえている） |
| `hi_kozue` | 高校の三年間、梢のバンド「夜光虫」でベースを弾いた。卒業で抜けた（進学しない自分が、そこにいていいと思えなかった）。梢はいまも店に来て、ふつうに話しかけてくる。ベースは押し入れ |
| `!hi_kozue` | 梢とは同じクラスだったが、一度も話したことがない。梢はギターを背負って店に来るが、自分のことは覚えていないと思っている |
| `hi_no` | 週五の夜勤。店長の「もう一日」を一度断れた。少しだけ自分の時間がある |
| `!hi_no` | 週六の夜勤。店長の頼みを全部受ける。昼も眠れない |

湊の会話で立つフラグ：
| フラグ | 立つ返事 | 意味 |
|---|---|---|
| `mi_draw` | 絵の話でのちょうどいい返事（!hi_draw なら「手がおぼえてるのは、捨てたことにならない」、hi_draw なら「誰か一人にだけ、一枚見せてみる」） | 描くことを（もう一度／もう一歩）自分のものにする |
| `mi_tell` | 七海への片思いの話で、**背中の押し方がちょうどいい**返事（「言うか言わないかは自分で決めていい。でも、決めるのは自分で」＋「まず、温めますかの次に、ひとことだけ」など、小さな一歩） | いつか自分の言葉で七海に想いを伝える、と自分で決める |
| `mi_rush` | 同じ場面の「近すぎ」（「今夜言いましょう、絶対後悔しますよ」と代わりに決める） | 翌日レジで唐突に言ってしまい、七海を困らせる。七海はその時間に来なくなる |
| `mi_no` | 店長・シフトの話でのちょうどいい返事 | 断ることを覚えはじめる |
| `konbini_words` | 結びの場面「温めますか、のあとに自分の言葉をひとこと足す」 | 客に、ひとことだけ話しかけるようになる（桐島・梢・遥ルートへの波及） |

### 3-3. ルート（エンジンが計算。条件式 `route:nanami` `route:haruka` `route:alone`）
```
nanami（七海ルート）: mi_tell かつ !mi_rush かつ ok:ol
haruka（遥ルート） : nanami でなく、かつ（ok:konbini または konbini_words または good:student）
alone （ひとりのルート）: それ以外
```
- **七海の結果が湊の人生を左右する**（つながりの波及）。七海が「届いた／少し届いた」＝自分に向けられた言葉を受け取れる人になっていれば、湊の言葉は届く。七海が「届かなかった」なら、湊が渡したひとこと（レシートの裏のメモ）は、七海が怖くて読めないまま鞄の底に残り、湊は「返事がない＝だめだった」と思う。

### 3-4. 絵の度合い（条件式 `draw2` `draw1` `draw0`）、断る力（`sayno`）
- `draw2`＝hi_draw かつ mi_draw：自分の絵で食べている（絵本と挿絵のイラストレーター。月と猫の画風。「拓海」の名前で）。
- `draw1`＝どちらか一方：デザイナー。仕事は人の注文どおりのチラシやバナー。夜中に自分の絵を描いているが、誰にも見せていない。
- `draw0`＝どちらもなし：下請けの DTP オペレーター。人の作ったデータを言われたとおりに直す仕事。絵は描かない。
- `sayno`＝hi_no または mi_no：拓海は「断れない」けれど、断ろうとして言葉を探せる人。`!sayno` だと案件九本、睡眠三時間、もう言葉が出てこない。

## 6. 相談者の会話の作り方（ルール）
- 来室（電話）の描写 → 語り（何回かに分けて）→ 返事の選択 → 反応 → さらに語り → … を **選択5回**（最低4回）。
- 一人あたり本文（地の文＋セリフ、選択肢を除く）で **どの経路を通っても3000字以上**。分岐する枝はそれぞれちゃんと書く。
- 返事カードは各回3〜4枚。種類 `k`：near（寄り添いすぎ）／far（突き放しすぎ）／just（ちょうどいい）／odd（変化球。効くなら `good:true`、外すなら `good:false` と `m`）。どれがちょうどいいかは相手と流れ次第。カードの並び順もばらばらに。
- カード文は **45字以内**。「」はつけない。動作は「（黙って、珈琲を注ぎ足す）」のように全角丸括弧で始める。
- **選んだ返事ごとに反応 `r` を個別に書く（使い回し禁止）**。2〜6行程度。
- 少なくとも1〜2か所、選択で次の語りの中身が変わる分岐（`go`）。
- 表情 `{f, say}` をこまめに変える。say は15字以内。
- 前の夜のフラグ・結果・ルートで、セリフや展開が実際に変わる箇所（`{if}`）を指定のとおり入れる。
- 名前は最初は `anon` で表示し、名乗ったところで `{reveal:true}`。
- 相談の最後は、帰っていく描写（電話なら受話器を置く音、ツー、ツーという音、窓の外）で締める。
- **時をこえる仕掛けを、地の文でもセリフでも説明しない。** 手がかりは物と言葉で置くだけ。相談員の独白で「似ている」と言わない（腕時計に一瞬目が留まる、程度まで）。
- **組Aの女性三人（七海・梢・遥）は別人。似ていることに触れない。**

## 7. データ形式（JavaScript）

**ファイル**：`story/frame1.js`〜`frame5.js`（夜の枠）、`story/<ID>.js`（相談者ひとりずつ）、`story/epilogue.js`。どれも `window.STORY` に追記する。

```js
(function (S) {
  S.visitors.ol = {
    id: 'ol', night: 1,
    name: '春日 七海', short: '七海', anon: 'スーツの女性', label: '二十六歳・会社員',
    img: 'assets/v_ol.jpg',
    phone: false,                 // 電話の相談者は true（student, child, freelance）
    routeName: { haruka: '三好 遥' }, // （任意）ルートで正式名が変わる人だけ
    face: { f: 'tense', say: 'こんばんは……' },
    script: { start: [ /* ステップ */ ], label2: [ ] },
    outcome: { good: { f, say }, mid: { f, say }, bad: { f, say } },
    letterStyle: 'round', // round neat pencil shaky receipt staff child brush sketch
    letters: {
      good: { text: `本文（400〜700字。\n で改行）`, sign: '春日七海' },
      mid: { ... }, bad: { ... },
      // （任意）ルート別：good_nanami / mid_haruka / bad_alone … があればそちらを優先（拓海は9通すべて書く）
    },
  };
})(window.STORY = window.STORY || { visitors: {}, nights: {}, epilogue: {} });
```

### ステップ一覧
| 書き方 | 意味 |
|---|---|
| `'文字列'` | 地の文 |
| `['ol', 'セリフ']` | セリフ。話者：相談者ID / `me` / `dj` / `cat` / `radio` / それ以外の文字列はそのまま名前（例 `['店長','…']`）。「」はつけない |
| `{ f: 'smile', say: 'ひとこと' }` | 表情とひとこと |
| `{ choice: [ ... ] }` | 返事カード |
| `{ if: '条件', then: [...], else: [...] }` | 条件分岐 |
| `{ go: 'ラベル' }` | ラベルへ移る |
| `{ set: 'フラグ' }` / `{ set: ['a','b'] }` | フラグ |
| `{ dj: 1 }` / `{ cat: 1 }` | ナツメ／猫との距離 |
| `{ time: '1:05' }` | 時計 |
| `{ sfx: 'door' }` | door phone pour tune rain thunder page clock |
| `{ fx: 'dark' }` | dark candle none rain snow dawn |
| `{ show: 'cat' }` | 胸像：相談者ID / 'dj' / 'cat' / 'none' |
| `{ reveal: true }` | 名乗った |
| `{ name: 'ヨル' }` | 表示名を変える（猫・DJ用） |
| `{ pause: 800 }` | ひと呼吸 |

### 選択肢
`t` カード文（45字以内）、`k` 種類、`r` 反応、`go`、`set`、`dj`/`cat`、`good`（odd のみ）、`m`（メーター上書き。負＝近すぎ、正＝遠すぎ。odd の good:false では必須）。

### 条件式
`フラグ名`、`!フラグ名`、`good:ID` `mid:ID` `bad:ID` `ok:ID`、`tie:T1`〜`tie:T8`、`conn`、`djhigh`、`cathigh`、`dj>=N` `cat>=N`、**`route:nanami` `route:haruka` `route:alone`**、**`draw0` `draw1` `draw2`**、**`sayno`**。`&`（かつ）`|`（または）、`&` が先に結合、括弧なし。
※ `route:*` は第二夜の湊の会話が終わったあとで確定する（それより前の夜では使わない）。

### 夜（frameN.js）
```js
S.nights[1] = {
  title: '第一夜', sub: '…', jingle: 'FMあさなぎ 78.3MHz　ナツメの真夜中便', weather: 'none',
  order: ['ol', 'dj', 'student', 'cat'],
  clock: { open: '23:40', ol: '23:50', dj: '1:30', student: '2:20', cat: '4:05', close: '4:50' },
  prologue: [ ], dj: { face, script: { start: [ ] } }, cat: { face, script: { start: [ ] } },
  monologue: [ ], morning: [ ],
};
```

### エピローグ（epilogue.js）
```js
S.epilogue = {
  intro: [ ],          // 第五夜の夜明け。源さんの電話（名乗る・千鶴の「よその夜につながる電話」の話）
  people: { ol:{good,mid,bad}, salaryman:{…}, musician:{…}, grandpa:{…}, konbini:{…} },  // 「今」の人たちの春（この順に流れる）
  life: { nanami:[ ], haruka:[ ], alone:[ ] },   // 「彼の物語」：陽向＝湊＝拓海の真相と、十二年の人生（ルート別。中で draw/sayno/結果/フラグで分岐）
  future: { mother:{good,mid,bad}, child:{…}, madam:{…} },  // 十二年後の人たちのその後（この順）
  dawn: [ ],           // 春の夜明けの店。ナツメ再登場（djhigh で変化）
  djLetter: { high:{text,sign:'灯'}, low:{text,sign:'ナツメ'} },
  endings: { A:{name,quote,script}, B:{…}, C:{…}, D:{…} },  // 各2000字以上
  routes: { nanami:{name:'ふたつめの杏仁豆腐'}, haruka:{name:'お月さまの客席'}, alone:{name:'ひとりぶんの灯り'} },
};
```
流れ：intro → people → life[route] → future → dawn → ナツメの手紙 → endings[A-D].script → エンディング画面。
