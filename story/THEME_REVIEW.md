# 最上位テーマの検討メモ（r0）

> **ここは、人生を変える場所ではない。ただ、人生が変わることもある。**

対象：BIBLE.md 第三版（追加指示10〜19、Codex 整合性修正、2026-10-28 の手紙方針・told_date 台詞まで反映後）の構想と、それに沿って書いた story/ の本文。
目的：依頼者が方針を決めるための材料。**r0 では人物設定・ルート構造の大きな変更はしていない。** 小さな調整だけ反映し、それを「4. r0 で反映したこと」に書いた。

## 1. テーマがよく表現できている部分

| 場面 | 理由 |
|---|---|
| 七海（第一夜）の「既読をつけるのが怖い」 | 相談員は既読を押させない。「届いたよの合図」という見方を一つ足すだけで、押すかどうかは本人に残る。good でも「押せた夜」ではなく「押してもいいと思えた夜」として書ける。 |
| 源さん（第三夜）の「ご飯を二人分炊いてしまう」 | 解決すべき問題ではなく、喪失そのもの。話して、おにぎりを一個いっしょに食べるだけの夜。テーマ1「ただ聞いてほしい」の典型。 |
| 遥ルートの未来の三好の電話 | 彼は過去を変えてほしいのではなく、七件の着信履歴を誰かに話したかった。電話の時点で相談は成立している（テーマ2）。相談員は彼が誰か確信できないので、「解決できる立場」を自覚する場面にならない。 |
| told_date／told_soft／伝えない の三択 | どれも free カード（メーター・結果に数えない）。相談員自身の判断として置かれ、ゲーム的な「正解」から切り離されている。 |
| 第四夜の alt4「停電の電話」 | 「まちがえました」で切れるだけの電話。何も起きず、何も解決しない夜を、それでも一つの夜として描く場所。 |
| 澄江とコースター | 澄江は描き主が娘の恋人だと知らないまま考えを少し改める。相談員の言葉ではなく、一輪の花と、たまたまそこにいた人の絵が人を動かす。相談員が「作者」でないことの好例。 |
| 桐島がコースターを拾う | 三好の人生を変えるのは相談員の助言ではなく、忘れ物の缶と、他人の目。相談員の選択（教える／本人に聞く／教えない）は、そのうちの一つにすぎない。 |
| ひとりのルートの救い | 結ばれなかった人生にも、黒電話の声と「温めますか」のあとのひとこと。「失敗ルート」に見せない設計。 |

## 2. テーマと緊張・矛盾している部分

### 2-1. 返事の良し悪しが人生を決めすぎる（Codex R14）
- 陽向の三つのフラグ（hi_draw / hi_no / hi_song）と三好の mi_tell が、それぞれ「ちょうどいい」カードでだけ立つ。結果として **just を多く選んだ周ほど、絵を続け、断れて、想いを伝えられる人生**になる。これはテーマ3「正しい返答を選んだから幸せになった、にしない」と構造的にぶつかる。
- 七海ルートの条件に `ok:ol` がある（七海の夜がうまくいかないと三好の告白も届かない）。物語としては美しいが、「第一夜の成績」が他人の恋を決める形にも読める。
- 現状の緩和策：どのルートにも光と影を書く（七海ルートの「寝て」、遥ルートのひよりの笑い声、ひとりの黒電話）。draw0 の人生（物流センターの主任）を失敗として描かない。

### 2-2. told_date の三択が「救いの段階」に見える（Codex R15）
- 伝える＝父が自分で119、ぼかす＝五回目で出る、伝えない＝七件と、**介入の強さに比例して被害が小さくなる**ように並んでいる。プレイヤーは「伝えるが正解」と読みやすい。
- 緩和策（r0 で反映）：told_date でも遥は倒れ、病気はなくならない。ひよりは「わたしだけ寝てた」とすねる。伝えない道では、ひよりがその夜を「わたしが救急車を呼んだ夜」と少し誇らしく語り、三好は断り方を覚えはじめる。よかったかどうかは書かない。
- それでも、三つの結果の「重さ」が介入量の順に並ぶ構造は残っている。

### 2-3. 「長年の後悔」と時間の近さ（Codex R03）
- テーマ2は「長年抱えてきた後悔」。現行の時系列では、未来の三好の電話は倒れた夜（七月）から数か月後。後悔は生々しいが、「長年」ではない。

### 2-4. 結果表示（届いた／少し届いた／届かなかった）
- 夜の終わりの「届かなかった」は、どう書いても判定に見える。手紙と後日談では謝罪・反省をさせない方針（10/28 03:55）を全員に適用したが、ラベル自体は残る。

### 2-5. 糸の本数とエンディング（Codex R18）
- エンディングは `conn`（糸4本以上）と `djhigh` で決まる。糸＝相談がうまくいった数に近いので、「人を多く救った周ほど良いエンディング」に見える可能性。どのエンディングも負けに見せない文章で緩和している。

### 2-6. ナツメの進路が好感度だけで決まる（Codex R17）
- djhigh なら町に残り、そうでなければ東京へ。ナツメ自身の仕事の選択が、相談員との距離の「ご褒美／罰」に見えるおそれ。low の手紙は「負けではなく、彼女自身の選択」として書くよう指示している。

## 3. 改善の提案（依頼者の判断待ち。r0 では未実施）

1. **陽向・三好のフラグを「ちょうどいい」以外にも散らす**：例として、hi_draw を「近すぎ」の返事（「絶対に美大に行くべきです」）でも立て、その場合は「描き続けるが、夢にして重くなる」別の色の人生にする。far でも hi_no が立つ（突き放されて、自分で断ることを覚える）など。正しい返事＝良い人生、の一対一をくずす。
2. **七海ルートの条件から `ok:ol` を外す、または弱める**：七海の結果は「三好のひとことの受け取り方」を変えるだけにして、ルートそのものは三好側の選択で決める。
3. **told_date の結果の並びを入れ替える案**：伝えた道にだけ生まれる別の影（たとえば、三好が毎年その日を恐れて過ごすことが家族の小さな謎になり、遥が「何か隠してる」と感じる時期がある）を少し太くする。伝えない道の光（ひよりの誇り、三好が変わるきっかけ）も太くする。
4. **「長年の後悔」との調整**：(a) 未来の三好の電話を倒れた夜から数年後に移し、ひよりの電話と学芸会の時期を再設計する、(b) 現行のまま「長年」をテーマ文の解釈で吸収する、のどちらか。
5. **夜の結果ラベルの言い換え**：「届いた／少し届いた／届かなかった」を、たとえば「灯りを持って帰った／灯りを少し／また夜に」のような、相談員側の判定に見えにくい言葉に変える（エンジンの表示文字列の変更のみで可能）。
6. **エンディング条件に「その周で一人の人とどれだけ長くいたか」など、量ではない軸を足す**案（構造変更になるので要検討）。

## 4. r0 で反映した小さな調整

- bad／mid の手紙・後日談で謝罪・反省をさせない（BIBLE §10-9。全員に適用）。
- told_date の結果を「父が在宅、自分で119、ひよりは眠っている」に統一し、ひよりの「わたしだけ寝てた」という影を明記。told_soft も短い時系列を確定（§10-4）。どの結果も「よかったかどうか」を書かない。
- 絵を仕事にする人生の影（締め切り、描くのが楽しかった頃を思い出せない夜）と、絵を仕事にしない人生の良さ（同僚に頼られ、昼に眠り、ときどき描く）を、未来の三好の電話とエピローグで両方書く。
- 第四夜の alt4（何も解決しない夜）を残し、説教しない独白にする。
- ナツメの最後の手紙で彼に触れるのは、その周で実際に起きた出来事だけ（hi_song の葉書／コンビニの青年とのやりとり）。存在しない救いを持ち出さない。
- ひよりの電話は長く引き止めず、パパかママのところへ行けるように背中を押して早めに切る（「助けることにも意味がある」）。
- エンディング D を、さびしいけれど誠実で静かに明るい終わり方にする。
