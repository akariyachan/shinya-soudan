## ★ 最上位テーマ（すべての執筆の上に置く）

> **ここは、人生を変える場所ではない。ただ、人生が変わることもある。**

- 相談室は問題を解決する場所ではない。話したい、整理したい、言えなかったことを口にしたい、ただ聞いてほしい――その夜の相談は、解決しなくても成立している。
- 何気ないひとことが、何年もあとになって人生を変えることもある。ただしそれは相談員が意図した結果とは限らない。**相談員は他人の人生の作者ではない。** 相談員の言葉は、人生をつくる無数の要素の一つにすぎない。
- 「正しい返事を選んだから幸せになった」「間違えたから不幸になった」という単純な因果にしない。どの道にも光と影がある。とくに三好の未来では、**絵を仕事にできることが幸福だけをもたらさない**（締め切り、断れなさ、描くことが楽しくなくなる夜）。絵を仕事にしなかった人生にも、ちゃんと手ざわりのある良さがある。
- 結末は答え合わせにしない。救いの分岐をご褒美として描かない。届かなかった（bad）結末も「罰」ではなく、その人がその夜ここへ来たこと自体に意味がある書き方にする。
- この思想を登場人物に語らせない。教訓として説明しない。「話して少し楽になっただけの夜」「何も解決していないけれど誰かと同じ時間を過ごせた夜」「何年もあとで意味が分かる言葉」を場面で積み重ねる。
- ただし「解決しないこと」が正義なのでもない。具体的な助けが必要な場面（九歳の子の夜中の電話、倒れた人）では、助けることにも意味がある。解決を押しつけないことと、助けを拒むことは違う。

## 0. 文体の約束
- 静かで、少しユーモアがあり、説教くさくない。昭和の深夜ラジオと純喫茶の空気。地の文は「相談員の目」から（一人称「わたし」は使ってよいが多用しない）。
- 相談員（プレイヤー）は **性別・年齢・名前を書かない**。呼ばれ方は「相談員さん」「あなた」「店の人」。「彼」「彼女」で相談員を指さない。
- 悩みは「小さいけれど本人には大きい」。具体的な物（杏仁豆腐、進路希望調査票、炊飯器の目盛り、胃薬、コーンポタージュの缶、開けていない小包、着信履歴…）で語らせる。
- ちょうどいい返事とは「相手の言葉を受け止めて、少しだけ視点を足す」もの。答えを与えない。
- 地の文で珈琲、窓の外のネオン、月、真空管ラジオのノイズ、黒電話、坂道などを描く。
- 「以下同様」「（略）」などの省略は禁止。全部書き切る。

## 3. 三好の人生（**最重要**）— 隠れフラグとルート

### 3-1. 陽向（第一夜・電話）で立つフラグ
| フラグ | 立つ返事 | 意味 |
|---|---|---|
| `hi_draw` | 絵の話で「描くのが好きなのと、夢にするのは別でいい」方向のちょうどいい返事 | 描くことを「将来の夢」に変えずに、好きなまま持っていていいと知る → 描き続ける |
| `hi_no` | 頼まれごと（文化祭のポスター、クラスTシャツ…全部引き受けた）の話で「すぐ返事しなくていい。『考えさせて』と言っていい」方向のちょうどいい返事 | 断る／保留する練習をはじめる |
| `hi_song` | 救われた歌の話で「返事のいらない言葉として、ありがとうを出してみる」方向のちょうどいい返事。陽向は、毎晩聴いている深夜のFM（＝はじまったばかりの、ナツメの番組）に、「午前二時の自販機」のリクエスト葉書を出してみる、と自分で決める | 葉書の隅に月と猫を描いて出す。新人DJ（ナツメ）が番組で読み、曲をかける。**その放送を、十二歳の梢が聴いていた**（誰も知らない。梢自身も、葉書の主が誰かは知らない） |

※ 陽向は「将来の夢がない」。担任に「絵がうまいんだから美大とか」と言われ、クラスでは文化祭のポスターもクラスTシャツの絵も頼まれて全部引き受けた。「好きなことを仕事に」と言われるたびに、好きなことが重くなる。中三の不登校のころの話（「おじいさんの店で、猫がいて」。店の名前は言わない）。「午前二時の自販機」の歌詞「**何者にもならなくていい夜が、ひとつくらいあってもいい**」。夜光虫の初代ボーカルには、ありがとうを言えないまま（ライブハウスの前で出待ちする勇気がない）。

## 7. 相談者の会話の作り方（ルール）
- 来室（電話）の描写 → 語り（何回かに分けて）→ 返事の選択 → 反応 → さらに語り → … を **選択5回**（最低4回。free カードは数えない）。
- 一人あたり本文（地の文＋セリフ、選択肢を除く）で **どの経路を通っても3000字以上**（目安5000字前後）。
- 返事カードは各回3〜4枚。種類 `k`：near（寄り添いすぎ）／far（突き放しすぎ）／just（ちょうどいい）／odd（変化球。効くなら `good:true`、外すなら `good:false` と `m`）。どれがちょうどいいかは相手と流れ次第。カードの並び順もばらばらに。
- カード文は **45字以内**。「」はつけない。動作は「（黙って、珈琲を注ぎ足す）」のように全角丸括弧で始める。
- **選んだ返事ごとに反応 `r` を個別に書く（使い回し禁止）**。
- 少なくとも1〜2か所、選択で次の語りの中身が変わる分岐（`go`）。
- 表情 `{f, say}` をこまめに変える。say は15字以内。
- 前の夜のフラグ・結果・ルートで、セリフや展開が実際に変わる箇所（`{if}`）を指定のとおり入れる。
- 名前は最初は `anon` で表示し、名乗ったところで `{reveal:true}`。
- 相談の最後は、帰っていく描写（電話なら受話器を置く音、ツー、ツーという音、窓の外）で締める。
- **時をこえる仕掛けを、地の文でもセリフでも説明しない。** 手がかりは物と言葉で置くだけ。
- **女性三人（七海・梢・遥）は別人。似ていることに一切触れない。**
- **テーマ**：ちょうどいい返事でも「解決」させない。外れた返事でも、相手が「話せてよかった」と思える余地を残す（ただし反応は個別に、外れたなら外れたなりに）。

## 8. データ形式（JavaScript）

**ファイル**：`story/frame1.js`〜`frame5.js`（夜の枠）、`story/<ID>.js`（相談者ひとりずつ）、`story/epilogue.js`（intro・people・threads・dawn・routes）、`story/epilogue2.js`（life）、`story/epilogue3.js`（djLetter・endings）。どれも `window.STORY` に追記する。

```js
(function (S) {
  S.visitors.ol = {
    id: 'ol', night: 1,
    name: '春日 七海', short: '七海', anon: 'スーツの女性', label: '二十八歳・会社員',
    img: 'assets/v_ol.jpg',
    phone: false,                 // 電話の相談者は true（student, child, freelance）
    // child だけ： when: 'route:haruka',  // この条件のときだけ登場
    face: { f: 'tense', say: 'こんばんは……' },
    script: { start: [ /* ステップ */ ], label2: [ ] },
    outcome: { good: { f, say }, mid: { f, say }, bad: { f, say } },
    letterStyle: 'round', // round neat pencil shaky receipt staff child brush sketch
    letters: {
      good: { text: `本文（400〜700字。\n で改行）`, sign: '春日七海' },
      mid: { ... }, bad: { ... },
      // （任意）ルート別：good_nanami / mid_haruka / bad_alone … があればそちらを優先（freelance は9通すべて書く）
    },
  };
})(window.STORY = window.STORY || { visitors: {}, nights: {}, epilogue: {} });
```

### ステップ一覧
| 書き方 | 意味 |
|---|---|
| `'文字列'` | 地の文 |
| `['ol', 'セリフ']` | セリフ。話者：相談者ID / `me` / `dj` / `cat` / `radio` / それ以外の文字列はそのまま名前（例 `['店長','…']`）。「」はつけない |
| `{ f: 'smile', say: 'ひとこと' }` | 表情とひとこと（いま表示中の胸像に） |
| `{ choice: [ ... ] }` | 返事カード |
| `{ if: '条件', then: [...], else: [...] }` | 条件分岐 |
| `{ go: 'ラベル' }` | ラベルへ移る |
| `{ set: 'フラグ' }` / `{ set: ['a','b'] }` | フラグ |
| `{ dj: 1 }` / `{ cat: 1 }` | ナツメ／猫との距離 |
| `{ time: '1:05' }` | 時計 |
| `{ sfx: 'door' }` | door phone pour tune rain thunder page clock |
| `{ fx: 'dark' }` | dark candle none rain snow dawn |
| `{ show: 'cat' }` | 胸像を切り替え：相談者ID / 'dj' / 'cat' / 'none'（相談の途中でほかの人を一時的に映してよい。戻すときは自分のIDを show） |
| `{ reveal: true }` | 名乗った |
| `{ name: 'ヨル' }` | 表示名を変える（猫・DJ用） |
| `{ pause: 800 }` | ひと呼吸 |

### 選択肢
`t` カード文（45字以内）、`k` 種類、`r` 反応、`go`、`set`、`dj`/`cat`、`good`（odd のみ）、`m`（メーター上書き。負＝近すぎ、正＝遠すぎ。odd の good:false では必須）、**`free: true`**（相談員自身の判断のカード。メーターにも結果にも数えない。k は省略可。コースターを教えるか・未来を伝えるか・鉛筆を置くか、など）。

### 条件式
`フラグ名`、`!フラグ名`、`good:ID` `mid:ID` `bad:ID` `ok:ID`、`tie:T1`〜`tie:T8`、`conn`、`djhigh`、`cathigh`、`dj>=N` `cat>=N`、`route:nanami` `route:haruka` `route:alone`、`draw0` `draw1` `draw2`、`designer`、`pop_job`、`sayno`、`wakai`。`&`（かつ）`|`（または）、`&` が先に結合、括弧なし。
※ `route:*` `pop_job` `designer` `draw*` は第二夜の三好の会話のあとで使う（kiri_job は第三夜で決まるので、`designer` `draw*` を第四夜より前に使うときは注意）。`wakai` はエピローグでだけ使う。

### 夜（frameN.js）
```js
S.nights[4] = {
```

- 第五夜：`order: ['freelance', 'miyoshi', 'madam', 'cat', 'dj']`、`scenes.miyoshi = { show: 'konbini', face, title: 'シフト前', script }`。

- 窓：上げ下げ式の古い木枠の窓。少し開けると、夜の音（第一夜＝冷たい乾いた空気、坂の下の自販機の唸り／第二夜＝強い風、看板が鳴る／第三夜＝雨の音とにおい／第四夜＝満月の光、停電の静けさ／第五夜＝雪の気配、音の少なさ）が入る。

### 12-2. 小さな行為（データ形式 `acts`）
```js
{ acts: [
  { a: 'nod', r: [ /* 反応 */ ] },                       // （黙って、うなずく）
  { a: 'coffee', t: '（ホットミルクを温めなおす）', r: [ ] },  // t で文言を上書きしてよい（淹れなおす・温めなおす等）
  { a: 'record', song: '雨やどりのワルツ', r: [ ] },        // （レコードをかける ―「雨やどりのワルツ」）
  { a: 'window', r: [ ] },                               // （窓を少し開ける）
] }
```
- 語りの途中の、言葉を返すより黙っていたほうがいい「間」に置く。**各相談者に2か所以上**（どの経路を通っても2か所に出会えるように）。一か所に3〜4つの行為（四つ全部でなくてよい。場面に合わないものは外す）。
- 行為ごとに**専用の反応**を書く（使い回し禁止、各80〜250字）。行為そのものの描写（湯の音、針を落とす音、風）＋相手がそれをどう受け取ったか（話が少し進む、言いかけていたことが出てくる、何も言わずに肩が下がる……）。
- 行為は**メーターにも結果にも数えない**（エンジンが free として扱う）。フラグ・dj・cat は動かさない。`go` は使ってよい（合流先に戻る程度）。
- 電話の相談者（陽向・ひより・未来の三好）には、受話器ごしに伝わる形で書く：うなずく＝沈黙が伝わる（「……聞いてます？」）、珈琲＝注ぐ音が聞こえる、レコード＝受話器の向こうに曲が流れる、窓＝こちらの夜の音が向こうへ入る（時代のちがいを説明しない。手がかりになる程度はよい）。
- 停電中（第四夜 1:40〜3:30）はレコード不可。

### 12-3. 返事を受け取る「間」
- エンジンが自動で入れる：返事カードを選ぶ → 相談員のせりふ → **一拍**（ランプの揺らぎ／カップの湯気／ラジオのノイズ／沈黙）→ 反応。種類はカードの性質で自動に選ぶ（電話ではノイズが多め）。
- 特定のカードで種類を指定したいときは、選択肢に `beat: 'steam' | 'lamp' | 'noise' | 'silence' | 'none'`。地の文の途中に一拍置きたいときは `{ beat: 'silence' }` のステップ。
- 反応の書き出しは、言葉をすぐ返さず、受け取るしぐさ（目を伏せる、カップを持ち直す、受話器の向こうの息）から入ると効く。

### 12-4. 心のメモ（相談員の手帳）
- 相談者の語りの中の、**話の中でしか分からない小さなことば**（好きなもの、言いかけてやめた言葉、くり返し出てくる物）を《》でくくり、三つ目の要素に memo を付ける：
```js
['ol', '……毎晩、《杏仁豆腐》ひとつだけ買うんですよ', { memo: 'ol_annin', note: '杏仁豆腐。毎晩ひとつだけ。なぐさめ用と、ごほうび用を兼ねて。' }]
```
  - 画面ではそのことばが光る。タップすると手帳に書き留められる（タップしなくても話は進む）。手帳はメニュー（設定）の「手帳を読み返す」で読める。
  - `memo` の id は `相談者ID_英小文字`。`note` は手帳に相談員が書く一文（60字以内、短い走り書きの文体。評価や分析は書かない。「〜が好き」「〜と言いかけて、やめた」など見たまま聞いたまま）。
  - 《》は一行に一つだけ。memo のない行に《》を使わない。地の文に置くときは話者を null にする：`[null, '……', { memo, note }]`。
- **後の返事カード**に、そのことばを踏まえた特別なカードを足す（手帳にあるときだけ出る）：
```js
{ t: '（三十字前後）', k: 'just', memo: 'ol_annin', r: [ /* 専用の反応 */ ] }
```
  - **各相談者に1つ以上**（memo のことばも、それを使うカードも）。どの経路でも、ことばを拾える場所と、カードの出る場所の両方を通るように置く（ことばの場所より後のカード）。
  - 特別なカードは、ふつうのカード（3〜4枚）に**足す**（そのブロックは最大5枚）。ほかのカードを置きかえない。
  - k は just が基本（odd good:true でもよい）。**そのブロックの just カードがフラグを立てるなら、特別なカードも同じフラグを立てる**（聞いていたことで損も得もしない）。新しいフラグ・ルートを変えるフラグは立てない。
  - 反応は「覚えていてくれた」ことへの小さな驚き・照れ・ほどけを、その人らしく。大げさに感謝させない。問題を解決させない。
  - 手帳のことばは**その人の話のなかだけで使う**。別の相談者のことばのカードは作らない（陽向・三好湊・未来の三好を手帳で結びつけない。時をこえる仕掛けを手帳で示さない）。
- ナツメにも手帳のことばを一つ置いてよい（`dj_…`）。カードの dj の値は、そのブロックの just と同じにする。

### 12-5. ナツメとの場面を、各夜もう一つ（`scenes`）
- 各夜に、ナツメとの短い場面（1200〜2200字、選択0〜2回）を一つずつ足す。キュンとする瞬間を増やすが、**まだ言葉にしない距離**。告白・名前の呼び捨て・手をつなぐ等はしない。秘密（§2-1：十年前のあの夜、貼り紙を書いたこと）を先に明かさない。
- 選択は `free: true` か、dj を動かさないカードにする（ルート判定 `DJ_ROUTE_NEED=9`・`djhigh=18` の均衡を変えない）。フラグを立てる場合は新しい名前（`dj_walk1` など）にし、その後の新しい場面の中だけで使う。
- 閉店後の帰り道など、独白（monologue）のあとに置く場面は、夜の `after: ['キー']` に入れる（エンジンは独白のあと、夜明けのまとめの前に流す）。時刻は `clock` に書く。
- 置き場所（第1回で書いたもの）：第一夜 `walk1`、第二夜 `walk2`、第三夜 `sign3`、第四夜 `moonwalk4`、第五夜 `snow5`（中身は frame*.js を参照）。
- 書いた中身（第1回）：`walk1`＝坂の下の自販機で、ナツメが生まれてはじめての「もう一本」を当てる（`dj_walk1`）。`walk2`＝四階のスタジオの窓。番組の無人の深夜帯で流す「眠れない夜の一曲」を相談員に選ばせる（`dj_walk2_star`／`dj_walk2_lemon`）。`sign3`＝雨。ナツメは来ず、4:58 に、その曲が曲紹介なしで流れる（選ばなければ「白い灯台」）。`moonwalk4`＝満月が沈むのを自販機の前で見送る。当たりは「生まれて二回目」（`dj_walk4`）。`snow5`＝店の前の雪に、ナツメの足あとと雪うさぎ。5:45 にFMあさなぎの放送終了のアナウンス（昔の録音で、若いころのナツメの声が噛む）（`dj_snow5`）。どの選択肢も free で、dj の値は動かさない。新しいフラグは、これらの場面の中だけで読む。
